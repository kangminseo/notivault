자주 묻는 질문

알림이 저장되지 않아요.
단축어 앱 → 보관함 → 자동화에서 'Missed' 자동화가 켜져 있는지 확인해 주세요. 링크로 추가한 자동화는 iOS가 꺼진 상태로 넣습니다. 앱의 설정 → 단축어 설정 방법에서 [확인]을 눌러 연결을 확인할 수 있어요.

내용 없이 저장돼요.
카카오톡 등 해당 앱의 알림 설정에서 '미리보기'가 꺼져 있으면 iOS가 내용을 넘겨주지 않습니다.

예전 알림도 볼 수 있나요?
자동화를 켠 뒤에 온 알림만 저장됩니다.

다른 앱도 저장할 수 있나요?
단축어 앱에서 'Missed' 단축어를 편집해 알림을 받을 앱을 추가하면 됩니다.

FAQ

Notifications aren't saved.
In Shortcuts → Library → Automation, make sure the 'Missed' automation is turned on. iOS adds automations from a link turned off. You can check the connection in the app: Settings → Shortcut Setup Guide → Check.

Saved without text.
If message previews are turned off for that app, iOS does not pass the text.

Can I see older notifications?
Only notifications received after the automation is on are saved.

Can I save other apps?
Edit the 'Missed' shortcut in Shortcuts and add more apps to its trigger.
